# TerraTwin — безкоштовне розгортання на Vercel

Ця версія підготовлена для одного Vercel-проєкту: Vite/React віддається як статичний сайт, а Express API запускається як Vercel Node.js Function. Окремий Render-сервер і PostgreSQL для наявних маршрутів не потрібні.

## Що змінено

- Додано `api/[...path].ts`, який експортує наявний Express app для маршрутів `/api/*`.
- Додано `vercel.json` з командами встановлення/збірки, папкою результату та лімітом часу API-функції.
- Vite більше не вимагає `PORT` і `BASE_PATH` під час збірки: значення за замовчуванням — `5173` та `/`.
- Вилучено з Vite-конфігурації Replit-only dev plugins.
- Додано `.nvmrc` з Node.js 22 та правила ігнорування `.env`-секретів.

## Розгортання

1. Створи приватний або публічний репозиторій на GitHub та завантаж у нього вміст цієї папки (не потрібно завантажувати `.git`, `node_modules` або `dist`).
2. У Vercel натисни **Add New → Project** і імпортуй цей GitHub-репозиторій.
3. У налаштуваннях проєкту залиш Root Directory як `./` (корінь репозиторію).
4. Переконайся, що Framework Preset — **Vite**. Значення install/build/output вже записані у `vercel.json`; якщо Vercel пропонує їх вручну, використовуй:
   - Install: `pnpm install --frozen-lockfile`
   - Build: `pnpm --filter @workspace/terra-lunar-atlas build`
   - Output: `artifacts/terra-lunar-atlas/dist/public`
5. Environment Variables для базової збірки не потрібні. Не додавай `DATABASE_URL`, якщо окремо не вмикатимеш функціональність бази даних.
6. Натисни **Deploy**. Після успішного деплою перевір сайт та API: `/api/healthz` має повернути JSON зі статусом `ok`.

## Безкоштовний тариф і обмеження

Vercel Hobby безкоштовний для особистих, некомерційних проєктів. Функції не потребують окремого постійно запущеного сервера; перший запит після паузи може мати холодний старт. Діють місячні ліміти Vercel, а також обмеження зовнішнього сервісу OpenTopoData. Якщо проєкт використовується комерційно, перевір умови Vercel Hobby перед публікацією.

## Важливо про дані

Поточний API обчислює профіль рельєфу через OpenTopoData і тримає кеш у пам'яті процесу. У коді API-маршрутів не знайдено читання/запису PostgreSQL; Drizzle-пакет присутній у workspace, але поточним маршрутам не потрібен. Кеш у serverless-середовищі не є постійним сховищем і може скидатися між запусками.

## Перевірка після деплою

- Відкрий головну сторінку.
- Відкрий `https://ТВІЙ-ДОМЕН/api/healthz` — очікується `{"status":"ok"}`.
- Перевір розрахунок terrain profile у самому інтерфейсі.
- Якщо API повертає 404, перевір, що файл `api/[...path].ts` знаходиться в корені репозиторію, а не всередині `artifacts/terra-lunar-atlas`.
